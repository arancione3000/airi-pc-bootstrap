# Airi-PC Companion — Download

## Download

Use the published **[Airi-PC Companion `companion-v0.2.1` release](https://github.com/arancione3000/airi-pc-bootstrap/releases/tag/companion-v0.2.1)**.

Choose one:

- **[Windows installer — `AiriPC-Companion-Setup.exe`](https://github.com/arancione3000/airi-pc-bootstrap/releases/download/companion-v0.2.1/AiriPC-Companion-Setup.exe)**
- **[Portable package — `AiriPC-Companion-portable-windows.zip`](https://github.com/arancione3000/airi-pc-bootstrap/releases/download/companion-v0.2.1/AiriPC-Companion-portable-windows.zip)**

## Install / run

### Installer

Run `AiriPC-Companion-Setup.exe` and complete the Windows installation.

### Portable

Extract `AiriPC-Companion-portable-windows.zip` and run the packaged Companion executable.

## Connect

Open **Airi-PC Companion** and use its connection control to pair it with an available Airi-PC environment.

## Verify

When the Companion transport is paired and reachable, the application exposes its connection/auth state and safety controls. These indicators describe the Companion transport; they are not a guarantee that every remote Airi-PC deployment is reachable.

## Emergency stop

Use **STOP ALL** when you need the Companion's local automation controls disabled.

For the complete end-user flow, see [`docs/END_USER.md`](../docs/END_USER.md).
