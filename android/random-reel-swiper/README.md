# Random Reel Swiper

Android app that performs user-enabled randomized upward swipes using Android's AccessibilityService.

## Behavior

- Random delay between swipes: **10–60 seconds**
- Random central start/end coordinates and random direction (360°)
- Random up/down/left/right/diagonal movement with a slight curve
- Random gesture duration: **2–4 seconds**
- Avoids the top and bottom screen regions
- Floating **STOP** button in the upper-right corner while active
- Does not inspect accessibility window contents

## Use

1. Install the APK.
2. Open the app and tap **ABILITA ACCESSIBILITÀ**.
3. Enable **Random Reel Swiper** in Android Accessibility settings.
4. Return to the app and tap **START**.
5. Open Instagram/Reels or another scrolling app.
6. Tap the floating **STOP** button to stop immediately.

Android requires accessibility services to be enabled manually by the device owner.
