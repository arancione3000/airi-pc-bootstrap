# Airi-PC — Demo Plan

Airi-PC currently has **no bundled video or screenshot demo** in this repository. This page documents the recommended demo to create later; it is not a claim that the demo already exists.

## 30–60 second sequence

1. **0–5s — Landing:** show the GitHub repository and the `Try Airi-PC` section.
2. **5–15s — Download:** open the current `Airi-PC Companion` release and select the Windows installer.
3. **15–25s — Launch:** start the Companion and show its local UI and connection/auth state.
4. **25–40s — Computer use:** show one representative, non-sensitive computer-use action.
5. **40–50s — Verification:** show `/status`, `/ready`, or the project verifier completing successfully.
6. **50–60s — Source:** return to the repository/release page and show `@arancione3000` as creator and maintainer.

## Recommended message

> Airi-PC rebuilds a local Computer Mode runtime from a canonical GitHub source, then verifies the runtime before use.

## Thumbnail / banner concept

Use a simple split composition: Airi-PC Companion on the left, the GitHub repository on the right, and a small caption such as **“Local Computer Mode · Reproducible · Verified”**.

Do not imply cloud hosting, universal autonomy, production readiness, or a bundled public relay.
