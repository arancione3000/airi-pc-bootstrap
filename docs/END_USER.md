# Airi-PC — End User Guide\n\nThis guide is for people who simply want to try the **Windows Airi-PC Companion** without setting up the core development runtime.\n\n## 1. Download\n\nUse the published **[Airi-PC Companion release](https://github.com/arancione3000/airi-pc-bootstrap/releases/tag/companion-v0.2.1)**.\n\nChoose one:\n\n- **Installer:** `AiriPC-Companion-Setup.exe`\n- **Portable:** `AiriPC-Companion-portable-windows.zip`\n\nThe release is the recommended distribution surface for packaged Windows builds.\n\n## 2. Install or run\n\n### Installer\n\nRun `AiriPC-Companion-Setup.exe` and complete the Windows installation.\n\n### Portable\n\nExtract `AiriPC-Companion-portable-windows.zip` and run the packaged Companion executable.\n\n## 3. Connect\n\nOpen **Airi-PC Companion** and use its connection control to pair it with the Airi-PC environment when a supported transport is available.\n\nThe Companion is designed to remain local by default. The repository does not bundle a public relay or a remote credential.\n\n## 4. Verify the connection\n\nWhen the Companion transport is paired and reachable, the application exposes connection/auth state. The existing Companion documentation uses these indicators as the expected healthy state:\n\n- `Connection: ONLINE`\n- `Authentication: OK`\n- `PC: CONNECTED`\n\nThese indicators describe the Companion transport; they are not a claim that every remote Airi-PC deployment is reachable.\n\n## 5. Emergency stop\n\nUse **STOP ALL** when you need to stop the Companion's local automation controls. The current Companion implementation uses this as a local safety control.\n\n## 6. Important limitations\n\n- The Companion is a **desktop control surface**, not the complete Airi-PC runtime by itself.\n- The current repository does not provide a public remote relay.\n- Do not paste API keys, access tokens, cookies or passwords into repository files.\n- The Game Agent foundation is intentionally generic and does not provide game-specific exploits or anti-cheat bypasses.\n\n## 7. If it does not connect\n\nStart with **[Troubleshooting](TROUBLESHOOTING.md)**. If the problem is reproducible, open a GitHub Issue with the relevant version, operating system, exact symptom and safe diagnostic output. Never attach credentials or private runtime state.\n
