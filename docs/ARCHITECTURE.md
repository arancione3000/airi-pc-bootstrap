# Airi-PC — Architecture\n\nAiri-PC is split into a **public reproducible bootstrap/runtime** and a **separate Windows Companion**.\n\n## High-level flow\n\n```text\n                     GitHub / main\n                          │\n                          ▼\n                bootstrap + rebuild scripts\n                          │\n                          ▼\n                  local Airi-PC runtime\n                          │\n             ┌────────────┼────────────┐\n             ▼            ▼            ▼\n           MCP        Control Plane   Browser/GUI\n                          │\n          ┌───────────────┼────────────────┐\n          ▼               ▼                ▼\n      Reasoning       Jobs/Tasks       Verification\n        Engine        + orchestration   + Audit\n          │               │                │\n          └───────────────┴────────────────┘\n                          │\n                          ▼\n                    Git / persistence\n\n       Windows Companion (separate local control surface)\n```\n\n## Bootstrap and reproducibility\n\nThe public bootstrap is designed around reconstructing the runtime from the canonical `main` source rather than treating an old session as the source of truth. The repository includes explicit rebuild and verification scripts.\n\n## Computer Mode / MCP\n\nThe runtime exposes a local MCP surface for computer-use operations. The CI workflow checks `/status` and `/ready` and exercises representative browser, screenshot, mouse, scroll and keyboard tools.\n\n## Control Plane\n\n`computer/control_plane/` contains the orchestration layer. Relevant components include reasoning, task/job management, persistence, reliability/recovery, audit, verification, capability management, Git integration and model routing.\n\nThe Reasoning Engine is a persistent runtime component integrated into the Control Plane. Its state is runtime-owned and is not intended to be part of the public bootstrap state.\n\n## Model boundary\n\nThe current router defines ChatGPT as the sole reasoning authority. The model-gateway compatibility module is intentionally disabled rather than acting as an active provider gateway.\n\n## Windows Companion\n\n`airi-pc-companion/` is a separate desktop application. Its local companion service binds to `127.0.0.1` by default and provides connection/auth state plus safety controls. It is not the core runtime itself.\n\nThe Companion also contains a generic Game Agent foundation with screen capture, state estimation, timing and safety controls. It intentionally does not implement game-specific exploits or anti-cheat bypasses.\n\n## Security boundary\n\nPublic source should contain implementation and examples, not runtime credentials. The repository has explicit ignore rules for local state and credential-like Companion files, and GitHub Secret Scanning/Push Protection are enabled. Remote MCP exposure must be authenticated and configured outside the public repository.\n
