# Airi-PC\n\n**A public bootstrap and Computer Mode runtime for Airi-PC, with a Windows companion for end users.**\n\nAiri-PC is built around a reproducible local runtime: the public repository contains the bootstrap/runtime source, verification scripts, tests, and the **Airi-PC Companion** Windows application source. The project is maintained by **[@arancione3000](https://github.com/arancione3000)**.\n\n> **Current status:** public project and active development. The Windows Companion has a published release; the core runtime is primarily a developer/advanced-user environment and is not presented as a turnkey cloud service.\n\n## 🚀 Just want to try it?\n\nIf you are a Windows user and want the simplest path, start with **Airi-PC Companion**:\n\n- **[Latest Companion release](https://github.com/arancione3000/airi-pc-bootstrap/releases/tag/companion-v0.2.1)**\n- **[AiriPC-Companion-Setup.exe](https://github.com/arancione3000/airi-pc-bootstrap/releases/download/companion-v0.2.1/AiriPC-Companion-Setup.exe)** — installer\n- **[AiriPC-Companion-portable-windows.zip](https://github.com/arancione3000/airi-pc-bootstrap/releases/download/companion-v0.2.1/AiriPC-Companion-portable-windows.zip)** — portable package\n- **[End-user guide](docs/END_USER.md)**\n\nThe Companion is a local desktop control surface. It can show connection/auth state and provides safety controls such as **STOP ALL** and **GAME MODE**. It does not bundle a public relay or an AI-provider API key.\n\n## What is Airi-PC?\n\nAiri-PC is a **Computer Mode runtime** designed to make a local automation environment reproducible across sessions. Its main building blocks include:\n\n- a canonical bootstrap/rebuild flow from GitHub;\n- a local MCP/HTTP runtime for computer interaction;\n- browser and GUI automation with recovery and verification paths;\n- a Control Plane with orchestration, task/job management, persistence, audit and verification components;\n- a persistent Reasoning Engine integrated with the Control Plane;\n- coding/agent tooling and Git integration;\n- reliability, watchdog and recovery mechanisms;\n- a separate Windows Companion for local physical-PC controls.\n\nSee **[Architecture](docs/ARCHITECTURE.md)** for the verified high-level structure.\n\n## What problem does it solve?\n\nAiri-PC focuses on a practical problem: **rebuilding and verifying the same computer-use runtime instead of depending on an unreproducible session state**. A fresh runtime can be reconstructed from the public `main` branch and checked by the repository's verification tooling.\n\nThe project is therefore useful both as a working Computer Mode environment and as a reference implementation for reproducible local automation infrastructure.\n\n## What it does *not* do\n\nTo keep the public description accurate:\n\n- it does **not** ship API keys, access tokens, cookies, passwords or private credentials;\n- it does **not** provide a bundled public relay for remote Companion access;\n- the current model-routing layer is intentionally **ChatGPT-only** rather than a multi-provider fallback system;\n- the Windows Companion does **not** expose arbitrary shell execution;\n- the Companion's game-agent foundation does **not** contain game-specific exploits, anti-cheat bypasses or unrestricted process control;\n- this repository does **not** claim to be production-ready, universally autonomous, or secure against every possible threat.\n\n## How it works\n\nAt a high level:\n\n```text\nGitHub main\n   │\n   ▼\nbootstrap / rebuild\n   │\n   ▼\nlocal Airi-PC runtime\n   │\n   ├── MCP / Computer Mode\n   ├── Control Plane\n   │     ├── Reasoning Engine\n   │     ├── orchestration / jobs\n   │     ├── verification / audit\n   │     └── persistence / recovery\n   └── browser + GUI automation\n\nWindows Companion ── local safety/control surface\n```\n\nThe core runtime is local. Runtime-owned state is deliberately kept outside the public bootstrap source where possible.\n\n## Requirements\n\n### For the Windows Companion\n\n- Windows PC\n- Download the installer or portable release from the [latest release](https://github.com/arancione3000/airi-pc-bootstrap/releases/tag/companion-v0.2.1)\n\n### For the core runtime / development\n\nThe core bootstrap is intended for an advanced Linux/development environment. The repository includes Python dependencies, shell entrypoints, Playwright-based browser automation and a substantial test suite.\n\nFor the maintainer/developer path, see **[Developer Guide](docs/DEVELOPER.md)**.\n\n## Core bootstrap\n\nThe canonical source is `main`. The public bootstrap deliberately follows a download → verify → execute model rather than `curl | sh`.\n\nFor a fresh runtime, the main entrypoints are:\n\n```sh\n./scripts/airi-next-session\n./scripts/airi-rebuild\n./scripts/airi-selftest\n./scripts/airi-coding-selftest\n./scripts/airi-runtime-verify\n```\n\nThe exact environment and paths used by the canonical CI/runtime are documented in **[Developer Guide](docs/DEVELOPER.md)**.\n\n## Verification\n\nThe repository has GitHub Actions workflows for:\n\n- **Airi-PC runtime verification** — shell validation, Python compilation, environment creation, static rebuild checks, runtime startup, tests and runtime verification.\n- **Airi-PC Companion Windows** — Windows packaging, installer creation, portable archive creation and release publication for `companion-v*` tags.\n\nThe last verified `main` CI run before this documentation update completed successfully on commit `e4e2aa7`. Local syntax compilation also passes on the current source snapshot. The full Python suite requires the repository dependencies; a dependency-free local run is not treated as a full test pass.\n\n## Security\n\nSecurity is part of the publication process.
