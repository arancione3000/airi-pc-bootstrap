## Stats

Token counts use OpenAI's `cl100k_base` encoding (`tiktoken`). Other tokenizers will
give somewhat different numbers, but this is a reasonable ballpark for most models.

| Text | Words | Tokens |
|---|---:|---:|
| The Willows | 19,550 | 23,967 |
| The Wendigo | 18,379 | 23,376 |
| Shadow over Innsmouth | 13,258 | 16,691 |
| Call of Cthulhu | 11,774 | 14,937 |
| The Temple | 5,366 | 6,606 |
| The Festival | 3,580 | 4,601 |
| Cool Air | 3,396 | 4,285 |
| **Total** | **75,303** | **94,463** |

**94,463 tokens** across 7 texts — roughly 432 KB of plain UTF-8 text.

<details>
<summary>Reproduce these numbers</summary>

```bash
python3 -c "
import tiktoken, glob, os
enc = tiktoken.get_encoding('cl100k_base')
total = 0
for f in sorted(glob.glob('texts/*.txt')):
    text = open(f, encoding='utf-8').read()
    n = len(enc.encode(text))
    print(f'{os.path.basename(f):28} {len(text.split()):>7,} words {n:>7,} tokens')
    total += n
print(f'{\"TOTAL\":28} {total:>23,} tokens')
"
```
