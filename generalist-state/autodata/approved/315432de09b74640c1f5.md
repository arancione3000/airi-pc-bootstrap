# Linguistic-Markers-of-Anorexia-and-Bulimia-Nervosa-in-Italian
This repository contains the code for the analyses reported in: “Linguistic Markers of Anorexia and Bulimia Nervosa in Italian Online Forums:A Corpus Based Study of Emotional Expression and Agency Framing” (submitted for revision)

## Overview
This repository includes:

- Python scripts for web scraping and NLP analyses
- R scripts for statistical analyses
- Documentation of the computational environment for reproducibility

## Data Availability
The datasets analyzed for this study consist of corpora compiled from publicly available blog posts collected via web scraping. Due to copyright and data protection considerations, the full raw texts cannot be publicly shared. Access to the raw corpus may be granted upon request, subject to compliance with the original websites’ terms of service. Requests should be directed to: valentina.alimenti@uni-bielefeld.de
