# Pandas Load Datasets CSV JSON

This example demonstrates how to load different types of datasets (CSV and JSON) into a Pandas DataFrame. It uses `io.StringIO` to simulate reading from files directly from strings, showcasing `pd.read_csv` and `pd.read_json` functions. This is a fundamental step in data analysis workflows.

## Language

`python`

## How to Run

1. Ensure you have Python and Pandas installed (`pip install pandas`).
2. Save the code as `main.py`.
3. Run from your terminal: `python main.py`
