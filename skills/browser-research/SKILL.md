# browser-research

## Description
Multi-source web research using Airi-PC browser/network evidence collection.

## Instructions
Start with the research topic and desired source count. Prefer independent sources. Collect explicit source URLs, titles and excerpts; record blocked sources as errors. Return evidence to the calling agent for synthesis instead of pretending the fetcher performed semantic fact-checking.
