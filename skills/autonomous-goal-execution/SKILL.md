# autonomous-goal-execution

## Description
Reusable bounded workflow for goal execution with persistent task/checkpoint state.

## Instructions
Start from a goal, reuse matching skills, execute bounded steps, verify each result, preserve checkpoints, and resume unfinished work in a later session. Never bypass safety or human-review boundaries.

## Tools
- computer_autonomous_goal
- computer_task_start
- computer_task_update
- computer_recovery_checkpoint
- computer_test_run
