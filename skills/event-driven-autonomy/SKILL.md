# Event Driven Autonomy

## Description
Use Airi-PC Reflex, ARD Skill Hunter and the independent Judge to complete long-running goals with minimal user intervention.

## Required tools
- computer_reflex_rule_add
- computer_reflex_status
- computer_resource_discover
- computer_resource_stage
- computer_resource_acquire_skill
- computer_judge

## Instructions
For work that depends on an external event, register a narrow Reflex rule instead of asking the user to poll manually.

When a required capability is genuinely missing, search ARD, keep relevance separate from trust, quarantine the candidate, and promote only a validated Markdown skill from an explicitly trusted publisher.

Before declaring a meaningful software change complete, use the independent Judge with explicit checks. Treat Judge failure as a reason to diagnose and continue rather than as a successful completion.
